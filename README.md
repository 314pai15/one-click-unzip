# 一键解压缩工具

批量解压目录下所有 `.zip` / `.rar` / `.7z` 压缩包，并提供批量清理压缩包功能。专门解决「下载目录里堆了几十个压缩包，一个个右键解压太麻烦」的问题——一条命令（或点一次按钮）全部解压到位。

## 主要功能

- **批量解压**（CLI + 图形界面）：自动扫描目录下的 zip / rar / 7z，解压到同名子文件夹
- **中文文件名修复**：自动识别 GBK 编码的 zip，解决解压后文件名乱码问题
- **递归模式**（可选）：递归扫描子目录，支持解压产物中嵌套的压缩包
- **加密压缩包**：通过 `--password` 参数统一提供密码
- **安全防护**：防 Zip Slip 路径逃逸攻击，恶意压缩包无法写出解压目录
- **批量删除压缩包**：解压完成后可一键清理原始压缩包，采用「先预览、再确认」的安全流程

## 安装方法

需要 Python 3.8+（无其他必装依赖）。

```bash
# 可选：启用 RAR 支持（还需安装 WinRAR，或将 unrar.exe 加入 PATH）
pip install rarfile

# 可选：启用 7z 支持
pip install py7zr
```

未安装上述库时，zip 解压不受影响，程序会提示缺什么。

## 使用方法

### 命令行版

```bash
# 解压指定目录（只扫描第一层）
python 一键解压缩.py D:\downloads

# 递归扫描子目录（含解压产物中的嵌套压缩包）
python 一键解压缩.py D:\downloads -r

# 解压加密压缩包
python 一键解压缩.py D:\downloads --password 你的密码

# 不带参数则进入交互模式，提示输入目录
python 一键解压缩.py
```

退出码：`0` 全部成功，`1` 有失败，`2` 目录不存在或未找到压缩包。

### 图形界面版

```bash
python 一键解压缩GUI.py
```

- 「批量解压」页签：选择目录、勾选递归、可选填密码，点击「开始解压」，日志实时显示进度
- 「删除压缩包」页签：先「预览扫描」确认文件清单，再点「确认删除」，防止误删

### 批量删除压缩包（命令行版）

```bash
python 批量删除压缩包.py D:\downloads
```

会先列出所有待删除的 `.zip/.rar/.7z` 文件（预览模式，不实际删除），输入 `y` 确认后才执行递归删除。

## 常见问题

- **文件名乱码**：程序已自动处理 GBK 编码的 zip；7z 格式按规范存 UTF-16，天然无乱码
- **同名文件夹已存在**：会提示「重复文件将被覆盖」后继续，不会中断
- **RAR 解压提示找不到 UnRAR.exe**：安装 WinRAR 后即可，程序会自动在常见安装路径查找
